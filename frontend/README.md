# Frontend: Streamlit Dashboard + Folium Maps

Interactive geospatial user interface for exploring and inspecting risk levels, satellite tiles, and GLORIA indicator contributions.

## Running Locally
```bash
python -m venv .venv
# Activate environment (Windows PowerShell: .venv\Scripts\Activate.ps1)
pip install -r requirements.txt
streamlit run app.py
```
Open in browser: http://localhost:8501
