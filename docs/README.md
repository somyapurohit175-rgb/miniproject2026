# Documentation & Architecture

This directory holds project architecture diagrams, data dictionary references, and report drafts.

## Contents
- **Architecture Overview:** System pipeline flow from raw satellite data & GLORIA datasets to ONNX inference and the Streamlit dashboard.
- **Data Dictionary:** Detailed attribute schemas for GLORIA tabular datasets and Sentinel bands (e.g., NDVI, NDWI, SAR polarizations).
- **Report Drafts:** Academic / project milestone deliverables and progress reports.
